# 📰 Sumbar Terkini - Media Kit & Paid Promote Web App (2026)

> **"Suara Terdepan Informasi, Politik & Berita Viral Sumatera Barat dan Nasional"**

Aplikasi web modern, high-converting, single-page Media Kit & Paid Promote resmi untuk **Sumbar Terkini**, jaringan media digital dan berita viral terkemuka berbasis di Sumatera Barat, Indonesia.

---

## ⚡ Tech Stack & Architecture

- **Framework:** Next.js 15 (App Router), React 19, TypeScript
- **Styling:** Tailwind CSS dengan estetika *Modern Editorial Tech & News Portal* (Aksen Deep Slate `#0F172A`, Clean Gray/White Cards, dan Highlight Minang Crimson `#990000` & Amber `#D97706`).
- **Animations & Icons:** Framer Motion & Lucide React
- **Database:** **NONE (100% Static Hardcoded JSON / TypeScript Data Structure)** — Siap dideploy di platform manapun (Vercel, Netlify, Cloudflare Pages, GitHub Pages) dengan *zero-latency*, zero database cost, dan tanpa kendala konfigurasi eksternal.
- **Responsiveness:** Mobile-first, fully responsive di desktop, tablet, dan smartphone.

## ☁️ Deploy

Karena menggunakan arsitektur **100% static data**, aplikasi ini dapat langsung dideploy ke **Vercel**, **Cloudflare Pages**, **Netlify**, atau **GitHub Pages** tanpa perlu membuat database apapun.
